# MiMic

Usa tu celular como cámara y micrófono para tu PC.

## Descargar

Entra en Releases y elige una opción:

- **Instalador:** instala MiMic y el componente de cámara virtual.
- **Portable:** extrae el ZIP completo y ejecuta MiMicClient.exe.
  Conserva todas las carpetas incluidas.

En el portable puedes instalar la cámara virtual desde:
**Opciones → Instalar o reparar cámara virtual…**

## Versión de pruebas
